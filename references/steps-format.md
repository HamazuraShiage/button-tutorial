# 步骤格式与运行方式

渲染器只负责排版，不会操作软件或验证按钮是否有效。先完成真实采集，再填写清单。

## 运行

```text
node scripts/build_tutorial.mjs steps.json --out ./tutorial-output --node-modules /absolute/path/to/node_modules
```

需要 Node.js 22 或更新版本、Sharp 和能显示中文的本机字体。在仓库根目录执行 `npm ci` 安装已锁定的依赖，然后可省略 `--node-modules`。宿主提供现成运行时与库目录时，也可用它们运行并传入该参数。`--font-family` 可指定当前机器已有的字体族。渲染器本身不联网、不安装库、不依赖 PDF；`--help` 查看参数。

首次验证安装可在仓库根目录运行 `npm run example`。它用明确标记的合成测试图检查排版，不代表任何软件的真实界面；制作实际教程时必须替换成真实截图。

成功时输出 JSON：`html` 为网页路径，`images` 为各步标注图路径，`steps` 为步骤数。默认不产生 PDF、ZIP 或课程成品。

## 清单示例

下面只演示数据格式。截图和坐标必须换成本次真实素材，不能当成某个软件的实际教程。

```json
{
  "title": "把一张图片放进作品",
  "goal": "完成一次上传，并检查图片显示正确",
  "start": "已经打开作品编辑页面",
  "finish": "画布中显示刚上传的图片",
  "application": {"name": "实际软件名称", "device": "电脑"},
  "steps": [{
    "id": "A",
    "title": "点上传图片",
    "shot": "screenshots/01-upload.png",
    "target": [1050, 352, 1175, 400],
    "callout": [548, 172, 450, 116],
    "on_image_text": ["点这里", "上传图片"],
    "where": "右侧面板中的上传按钮",
    "action": "用鼠标点一下「上传图片」。",
    "result": "出现电脑的文件选择窗口。",
    "tip": "没有弹出时，检查是否有其他对话框挡住页面。"
  }]
}
```

## 字段

根字段 `title`、`goal`、`start`、`finish` 是必填非空字符串，`steps` 是非空数组。

可选 `application` 的 `name`、`version`、`device`、`system`、`browser`、`capture_date` 都是字符串。未知字段省略，不填假版本或假日期。

可选 `style`：`accent`、`background` 是十六进制颜色，`font_family` 是已有字体族，`font_size` 是原图像素单位的正字号。默认红色指示、浅色标注框、中文系统字体。

| 步骤字段 | 要求 |
| --- | --- |
| `id` | 可省略，依次生成 A…Z、AA；显式编号限 1–32 位英文字母、数字、下划线或短横线，不能重复 |
| `title` | 必填，当前动作的简短标题 |
| `shot` | 必填，真实 PNG/JPEG/WebP 路径，相对路径以 JSON 目录解析 |
| `target` | 必填，目标矩形 `[左, 上, 右, 下]` |
| `on_image_text` | 必填，图内动作文字，字符串或非空字符串数组；数组项表示有意分行 |
| `action` | 必填，可照做的完整动作或按键顺序 |
| `result` | 必填，动作后的可见结果 |
| `callout` | 可选，文字框 `[左, 上, 宽, 高]`；省略时自动做几何避让 |
| `protected` | 可选，不得遮挡的多个 `[左, 上, 右, 下]` 关键区域 |
| `where`、`tip` | 可选，位置说明与最相关的排错办法 |
| `zoom` | 可选，局部放大区域 `[左, 上, 右, 下]`；放大内容来自同一实图，在 HTML 内嵌展示 |

坐标均以 EXIF 正规化后的**显示方向原始像素**计，不用百分比或排版缩放后的坐标。`target`、`protected`、`zoom` 用两个角；`callout` 用位置与宽高，不能混用。

## 排版与错误

- 先看截图再设目标、标注框和保护区。自动放置只懂几何，不会识别教学重点，生成后仍需看图。
- 文字自动换行。固定框放不下时扩大框或拆步骤，不截字，也不缩到无法阅读。
- 截图缺失、坐标越界、编号重复、标注遮挡目标或保护区、文字无法容纳时应明确报错并指出步骤；修正清单再生成。
- 输出目录与素材分开；原图保持不变。主 PNG 含文字与箭头，局部放大内容直接内嵌 HTML，不额外产生一套图片文件。
